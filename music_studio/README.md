# Penny Music Studio — portable Phase 1 package

A standalone, pure-Python, CPU-first extension for Penny. Generates reproducible procedural country/pop/rock song sketches as multitrack MIDI and synthesised stereo WAV. **Not a neural text-to-song or singing-voice generator.**

From the folder containing `penny_music_studio` (for a GitHub checkout: `cd music_studio`):

```sh
python -m unittest discover -s tests -v
python -m penny_music_studio gui
python -m penny_music_studio create --prompt "country rock piano intro, guitar solo, dramatic final chorus key change" --bars 1 --out output
```

Documentation: [docs/MUSIC_STUDIO.md](docs/MUSIC_STUDIO.md). No dependencies needed for core CLI/synth. `tkinter` for UI; Windows `winsound` for playback; optional FFmpeg for MP3. These files are designed to be added, not to replace the private assistant.

**Current implementation:** independent Python composition backend, project model/persistence, standard MIDI export, preview WAV synthesis, optional FFmpeg MP3, basic Tkinter editor and cancellable background render worker. Nine tests passed in the development Linux environment; Windows hardware compatibility and integration into the private Penny assistant are not yet verified.

## SUSAN experimental neural composer

SUSAN v0.1 is a separate, **optional** trainable PyTorch GRU that learns symbolic melody notes from original synthetic songs generated by the procedural engine. This is not text-to-audio or singing-voice generation. The core Penny Music Studio remains dependency-free. Run `python -m penny_music_studio.susan status`, then follow [`docs/SUSAN.md`](docs/SUSAN.md) to install the optional CPU PyTorch runtime, train a local model and generate an editable song.
